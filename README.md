# meal-planner
A web application for automating recipe selection and meal planning, taking into account individual preferences, dietary restrictions, allergens, and current food stocks.

# Гармония вкуса — Meal Planner

Веб-приложение для автоматизации подбора рецептов и планирования питания с учётом индивидуальных предпочтений, диетических ограничений, аллергенов и текущих запасов продуктов.

## О проекте

**«Гармония вкуса»** — это полнофункциональная информационная система, которая помогает пользователям составлять персонализированный рацион на основе:

- **целевых показателей КБЖУ**, рассчитанных по формуле Миффлина-Сан-Жеора с учётом пола, возраста, веса, роста, уровня активности и цели питания;
- **диетических ограничений** (вегетарианство, веганство, без глютена, кето, палео и др.), хранимых в виде битовой маски;
- **аллергенов и исключённых продуктов**;
- **предпочтений по кухне** и **избранных рецептов**;
- **фактического наличия продуктов** на кухне пользователя.

Система автоматически формирует сбалансированное меню на произвольный период (до 31 дня) с помощью **генетического алгоритма**, генерирует **список покупок** с вычетом остатков и предлагает **гибридные рекомендации** рецептов (контентная + коллаборативная фильтрация).

## Основные возможности

| Раздел | Функционал |
| **Главная** | Дашборд с прогресс-барами КБЖУ за сегодня (превышение выделяется красным), виджеты продуктов, покупок и избранного |
| **Рецепты** | Расширенный поиск и фильтрация (категория, калорийность, время, сложность), карточки с изображениями, модальное окно с ингредиентами и инструкцией, добавление в избранное |
| **Моё меню** | Выбор периода, настройка количества приёмов пищи, блюд и напитков на каждый приём, генерация меню генетическим алгоритмом, ручная замена блюд через альтернативы, печать меню |
| **Продукты** | Учёт остатков, добавление через автодополнение, изменение количества, удаление |
| **Покупки** | Автоматическая генерация списка с учётом остатков, группировка по категориям, отметка купленного (добавляется в остатки), печать |
| **Профиль** | Антропометрия, цель и активность, диетические ограничения (10 масок), аллергии, исключённые продукты, избранные рецепты, история оценок |

## Математическое ядро

### 1. Расчёт целевых КБЖУ
- **BMR** по формуле Миффлина-Сан-Жеора:
  - мужчины: `BMR = 10×вес + 6.25×рост − 5×возраст + 5`
  - женщины: `BMR = 10×вес + 6.25×рост − 5×возраст − 161`
- **TDEE** = BMR × коэффициент активности (1.2–1.9)
- **Целевая калорийность**: похудение (×0.85), поддержание (×1.0), набор массы (×1.15)
- **Макронутриенты**: белки 25 %, жиры 30 %, углеводы 45 %

### 2. Генетический алгоритм формирования меню
- Параметры: популяция 50, поколений 100, мутация 0.05, кроссинговер 0.8, элита 5
- Функция приспособленности учитывает:
  - сбалансированность БЖУ (`Balance`),
  - разнообразие (`Variety`, штраф за повтор > 3 раз),
  - соответствие предпочтениям (`Preference`, бонусы за избранное и кухню),
  - ограничение калорийности дня (900–4000 ккал).
- Хромосома — меню на весь период, гены — идентификаторы блюд и напитков.
- Избранные рецепты имеют в 10 раз больший вес при выборе.

### 3. Гибридная рекомендательная система
- Контентная фильтрация: совпадение кухни (1.0 / 0.5).
- Коллаборативная: средние оценки пользователей из таблицы `recipe_ratings`.
- Итоговая оценка: `0.6 × content + 0.4 × (collab / 5)`.

### 4. Формирование списка покупок
- Агрегация ингредиентов из меню с учётом порций.
- Вычет текущих остатков (`required = max(0, needed − stock)`).
- Группировка по категориям продуктов.

### 5. Контрольные соотношения
- КБЖУ рецепта: отклонение ≤ 5 %.
- Калорийность дня: 900–4000 ккал.
- Повтор рецепта: ≤ 3 раз за период.
- Лимиты блюд и напитков на приём.
- Неотрицательность остатков (CHECK в БД).

## Установка и запуск

### Требования
- Apache 2.4+
- PHP 8.1+ (расширения: mysqli, pdo_mysql, json, curl)
- MySQL 8.0+
- Redis (опционально)

### Шаги установки

1. **Клонируйте репозиторий** в корень веб-сервера:
   ```bash
   git clone https://github.com/your-username/meal-planner.git
   ```
   Для XAMPP: `C:\xampp\htdocs\meal-planner\`.

2. **Создайте базу данных** и импортируйте схему:
   ```bash
   mysql -u root -p < db/schema.sql
   ```
   Или через phpMyAdmin: создайте БД `meal_planner`, затем импортируйте `db/schema.sql`.

3. **Настройте подключение** в `api/config.php`:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'meal_planner');
   define('DB_USER', 'root');
   define('DB_PASS', '');
   ```

4. **Запустите Apache и MySQL** (в XAMPP Control Panel).

5. **Откройте приложение** в браузере:
   ```
   http://localhost/meal-planner/
   ```
